# LPC JaidynReiman Assets

A curated collection of LPC (Liberated Pixel Cup) sprite assets authored or co-authored by JaidynReiman.

## Structure

- **characters/** — Character sprite layers following ULPC spritesheet structure. Each asset is organized as `{category}/{name}/{body_stage}/[{layer}/]{animation}.png`.
- **tilesets/** — Compiled tilesets assembled from existing LPC assets, with minor edits.
- **tilemaps/** — Maps built from existing tilesets.

## Sources

Assets are drawn from two repositories:

- [lpc-jaidynreiman-sprites](https://github.com/jrconway3/lpc-jaidynreiman-sprites) — JaidynReiman's primary sprite collection (takes priority)
- [Universal LPC Spritesheet Character Generator](https://github.com/Universal-LPC/Universal-LPC-Character-Generator) — ULPC upstream baseline

Only assets where JaidynReiman is a credited author in the ULPC sheet definitions are included. See [CREDITS.md](CREDITS.md) for full attribution.
