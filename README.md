# LPC JaidynReiman Assets

This is a curated collection of my contributions to LPC (Liberated Pixel Cup) sprite assets. Any assets either made by me or heavily alterred by me in some way will appear in this archive.

Check out my portfolio at [JR Productions](https://jaidynreiman.net)

## Structure

- **characters/** — Character sprite layers following ULPC spritesheet structure. Each asset is organized as `{category}/{name}/{body_stage}/[{layer}/]{animation}.png`.
- **tilesets/** — Compiled tilesets assembled from existing LPC assets, some with minor edits.
- **tilemaps/** — Maps built from existing tilesets, coming soon.
